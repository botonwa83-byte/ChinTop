# 截图与素材清单

> 位置：App Store Connect → App 版本 → App 预览与截图。
> ChinTop 是通用 App（iPhone + iPad），因此除 iPhone 截图外，还需要 iPad 截图。

---

## 一、必需尺寸

| 设备 | 典型竖屏分辨率 | 是否必需 |
|------|----------------|----------|
| iPhone 6.9" | 1320 x 2868 | 必需 |
| iPhone 6.5" / 6.7" | 1242 x 2688 / 1290 x 2796 | 可选，建议补 |
| iPad 13" | 2064 x 2752 | 通用 App 必需 |

每个尺寸 1-10 张。建议 6 张覆盖核心卖点。

## 二、建议截图脚本（6 张）

1. **登科之路首页**：展示主线、今日状态和顶部“解锁完整版”入口。
2. **采分点自评 / 采分殿堂**：展示关键词、术语、分值、阅卷人批注。
3. **默写星图 / 图鉴**：展示 64 篇默写和积累资产。
4. **文言解码**：展示 120 实词、18 虚词、逐字对译或文化常识卡。
5. **作文工坊**：展示材料作文、素材、骨架或升格卡。
6. **付费墙**：展示一次买断、恢复购买和解锁范围；同时作为 IAP 审核截图。

## 三、当前工程内置的截图启动参数

`ChinTopApp.swift` **未**内置 `-skipPromo` / `-demoXxx` 启动参数（ChinApex 的 demo 参数没有搬过来）。

取图建议：

- 首图直接进默认首页「学习主线」；
- 付费墙手动进入「功能宝藏」→「解锁完整版」。

## 四、取景建议

- iPhone 首图：用「学习主线」首页，让用户第一眼知道这是一款语文学习 App。
- 第二张放「题型场」，展示五大专题入口与题库量。
- 第三张放「能力图鉴」，突出五项能力量化。
- 第四张放「功能宝藏」，突出方法工具箱与成长报告。
- 第五张放具体练习页，展示逐题解析与错因定位。
- 第六张放「付费墙」，给审核和用户都讲清楚免费/付费边界。
