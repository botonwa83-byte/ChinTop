# ChinTop 开发进度 · 2026-09-11

## 第四轮：修复付费解锁链路（参照 EngTop）

### 问题根因

对照 EngTop（英语版）的解锁实现，ChinTop 的付费功能有 4 个缺陷：

1. **没有本地 StoreKit 商品配置**：EngTop 根目录有 `EngTopApp.storekit` 定义商品，ChinTop 没有 → `Product.products(for:)` 永远返回空，点购买必报"暂时无法获取购买信息"。
2. **scheme 未挂载 storekit 配置**：EngTop 的 scheme 含 `StoreKitConfigurationFileReference`，ChinTop 的 `project.yml` 连 scheme 都没声明。
3. **启动不核验购买凭证**：EngTop 初始化时 `loadProduct + refreshEntitlements`（且检查 `revocationDate`），ChinTop 只读 UserDefaults 缓存——重装/清数据后即使买过也会永久锁死。
4. **购买流程缺分支**：未处理 `.userCancelled`、`.pending`（家长确认）、未验证交易；恢复购买无"未找到购买记录"提示。

### 修复内容

| 文件 | 改动 |
|---|---|
| `ChinTopApp.storekit`（新增） | 本地商品配置：`com.chintop.app.full_unlock`，¥22 NonConsumable，zh_CN 文案 |
| `project.yml` | 新增 schemes 声明，run/test/profile 均挂 `storeKitConfiguration` |
| `ChinPurchaseManager.swift` | 整体对齐 EngTop 实现：启动核验凭证、pending/取消分支、`checkVerified` 统一验签、恢复未找到提示 |

### 验证

- `xcodegen generate` 后 scheme 正确生成 `StoreKitConfigurationFileReference` → `../../ChinTopApp.storekit`。
- `swift test`：26 项全绿。
- Catalyst Debug 构建：BUILD SUCCEEDED。

### 遗留

- App Store Connect 真实商品（同 ID、同价位）未创建；上线前需配置并做沙盒验收，不要宣称"支付已上线"。
- 本地购买流程建议在 Xcode 里用 storekit 配置实测一遍（本机无 Simulator runtime，本次为编译级验证）。

### 踩坑记录

批 5 写入时一处编译错误：`middle-writing-31` 的选项字符串把中文引号“”直接嵌在 ASCII 引号内且闭合错位，导致 `unterminated string literal`。修复方式：选项文本去掉中文引号；并新增"每行 ASCII 引号数必须为偶数"的快速扫描作为写题后的自检步骤。

### 权重模型

每个知识点在其覆盖学段内的题量下限按重要性配给：**核心 core ≥ 4、支撑 supporting ≥ 3、拓展 extension ≥ 2**（`ChinQuestionBank.targetCount`）。盘点首批 120 题后得出 67 题缺口，分三批填充：

| 批次 | 范围 | 填充明细 | 题量 |
|---|---|---|---|
| 批 1 | 现代文阅读 + 文言文 | 阅读：证据/结构/标题/语言/说明文/探究/策略等 21；文言：虚词/句式/翻译/写法/概括 8 | 29 |

填充后：小学 92 题、初中 95 题，共 187 题，每个"知识点×学段"均达权重下限。

## 第一轮：修复模块设置与模块间自洽性

### 中断点定位

| 问题 | 真实现状 | 处理 |
|---|---|---|
| 题库内容造假 | `ChinQuestionBank.buildAll()` 用模板批量生成 120 道题，同一知识点下题干、选项、答案完全相同；测试只校验结构所以全绿 | 整段删除生成器，注入 120 道人工题 |
| 真题目被弃用 | 约 110 道人工编写题滞留在 `ChinLegacyQuestionBank` 死代码中，未接入任何界面 | 迁移 98 道进入题库（按学段/知识点重新标注），删除死代码 |
| 知识点口径不自洽 | 模块"覆盖知识点"展示每模块 18 条手写清单，练习筛选器只有 3–5 条，两套互不相干 | 统一为题库目录 33 个细粒度知识点，两处同源取数 |
| 错题元数据链路断裂 | `ChinMistakeRecord` 有 `gradeID`/`knowledgePointID`/`difficulty` 字段，但 `recordPractice` 全链路不接收、不写入 | 三层 `recordPractice` 全部补齐参数并落库，旧错题再答时同步更新 |
| 能力映射靠猜 | 按中文技能名关键词匹配，新增知识点标题会归类错误 | 改为知识点 ID 表驱动（33 条），旧数据回退关键词匹配 |
| UI 文案写死 | 模块页写死"题库共 120 题"（实际每模块远不到 120） | 改为按当前学段 + 模块动态计数 |
